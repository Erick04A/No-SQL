¿Qué es un grafo?

Es una estructura de datos nativa diseñada para modelar relaciones. Olvídate de tablas rígidas: aquí los datos se conectan directamente formando redes que revelan patrones ocultos al instante.

"En un grafo, cada conexión tiene tanto valor como el dato mismo."

Los componentes

Nodo

La entidad

Representa una entidad: una persona, lugar, producto o concepto.

Relación

La conexión

Conecta dos nodos con dirección y nombre. Ej: CONOCE, COMPRÓ, TRABAJA_EN.

Propiedad

El detalle

Atributo clave-valor dentro de un nodo o relación. Ej: nombre: 'Ana', edad: 29.

Neo4J en una línea

Cypher es el lenguaje de consulta declarativo de Neo4J. Se lee de izquierda a derecha dibujando visualmente el patrón que deseas encontrar:

MATCH (p:Person)-[:KNOWS]->(q:Person) RETURN p, q

Esta consulta encuentra todos los nodos "Person" que están conectados por una relación "KNOWS" hacia otro nodo "Person", y devuelve ambos.
