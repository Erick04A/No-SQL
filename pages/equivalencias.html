De Relacional a Grafos

Tabla de Equivalencias

Concepto SQL (Relacional) Concepto Grafo (NoSQL) Descripción
Tabla
Ej. Tabla 'Usuarios'
Etiqueta de Nodo (Label)
Ej. Nodo con etiqueta :Usuario
Cada tabla se convierte en un tipo de nodo etiquetado
Fila
Ej. Registro de Juan Pérez
Nodo individual
Ej. Nodo específico (Juan Pérez)
Cada registro es ahora un nodo con propiedades
Columna
Ej. Columna 'Edad' INT
Propiedad
Ej. Propiedad { edad: 30 }
Los campos pasan a ser atributos del nodo
JOIN
Ej. Clave foránea usuario_id
Relación (Edge)
Ej. (Usuario)-[:COMPRÓ]->(Producto)
Las claves foráneas se convierten en aristas explícitas
Primary Key
Ej. id INT PRIMARY KEY
ID de Nodo (o Propiedad Única)
Ej. ID interno o propiedad con restricción UNIQUE
El identificador único persiste como propiedad del nodo
